# 常见问题（FAQ）—— 机顶盒变「去广告 DNS 盒子」

## 电脑解析不到 / nslookup 超时
1. 盒子 DNS 服务在跑吗：子系统里 `pgrep -a AdGuardHome`；没有就重启。
2. **上游必须走 TCP**：老盒子 UDP 常被封 → 用 `adg_upstream.py` 设 `tcp://223.5.5.5` 等（见教程第 5 步）。
3. 盒子能上网吗：`curl -sI http://www.baidu.com`（子系统只通 http）。

## 广告没被拦 / 拦截很少
- 过滤列表没加载：管理页「过滤器」看各列表规则数是否为 0。默认 https 列表下不了（老盒子），要用 **http 列表**（`adg_filters.py`）。
- 该域名不在列表里：可在管理页「自定义过滤规则」手动加 `||域名^`。
- **硬编码 IP / DoH** 绕过的广告、视频前贴片、YouTube 广告 → DNS 拦不到（正常）。

## 管理页打不开（http://盒子IP:3000）
- 是否同一局域网；服务是否在跑；端口 3000 是否被占。
- 首次是"设置模式"（只开 3000）；配置后才同时有 :53。

## 全家设备都要手动改 DNS 吗？
不用。把**路由器 DHCP 下发的 DNS 改成盒子 IP** → 全屋自动生效。也可只在个别设备上手动设。

## 盒子关机/重启会不会断网
盒子是 DNS **单点** → 它不在时解析会断。请在路由器设**备用 DNS**（如 223.5.5.5）。

## 想当"完整旁路由"（分流/代理）？
只做 DNS 去广告只需改 DHCP DNS；完整旁路由要把**网关**也指向盒子并做转发/分流，属进阶，需额外配置。

## 支持哪些盒子？
同类已 root 的安卓机顶盒（Android 4.4+ / armv7·arm64）。本项目在 B860AV1.1-T2（Android 7.1 / armv8）实测。

## 怎么卸载
见教程第 10 步：停服务、路由器 DNS 改回、删 `/root/AdGuardHome`。
