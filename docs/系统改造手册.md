# 系统改造手册 —— 机顶盒变「去广告 DNS 盒子」

## 原理
盒子当**局域网 DNS 服务器**：AdGuard Home 接收查询 → 命中广告/跟踪规则就拦（返回 0.0.0.0），
否则转发给上游 DNS。**不刷机、不改固件**，全在子系统（chroot）里。

## 分层
| 层 | 内容 |
|---|---|
| Android | 开机挂子系统 + chroot 调 `adgstart.sh` |
| Linux 子系统 | AdGuard Home（DNS :53 + Web :3000） |
| 网络 | 路由器 DHCP 把 DNS 指到盒子 → 全屋生效 |

## 数据流
1. 设备查询 `ads.example.com` → 盒子 :53
2. AdGuard 匹配过滤列表 → 命中则回 `0.0.0.0`（拦截）
3. 未命中 → 转发上游（**tcp://223.5.5.5** 等）
4. 结果回给设备

## ⚠ 关键坑（本盒子实测）
1. **UDP 被封**：子系统里对外 UDP 不通 → DNS 上游必须 **`tcp://`**（否则解析超时）。
2. **只能 HTTP/80**：AdGuard 的默认 https 过滤列表下不了 → 用 **http 列表**；
   AdGuard 二进制本身也只有 https 下载 → 在**电脑上**下好再传。
3. **端口**：DNS 用 53（需 root，chroot 内是 root）；管理页 3000。53/3000 前先确认没被占。
4. **单点风险**：盒子是 DNS 单点 → 路由器要设**备用 DNS**。

## 端口
| 端口 | 用途 |
|---|---|
| 53 (UDP/TCP) | DNS 服务 |
| 3000 | AdGuard Home 管理页 |

## 设为全屋 DNS
- 路由器 DHCP 的 DNS 指向盒子 IP；或每台设备手动设。
- 只 DNS = 去广告；完整旁路由（网关也指向盒子）= 进阶。

## 卸载/还原
停 `AdGuardHome`、路由器 DNS 改回、删 `/root/AdGuardHome` 与启动脚本那行。
